# 🩺 Health Risk Prediction & Dietary Recommendation System

AI-powered bilingual health risk prediction and dietary recommendation system using Machine Learning, Flask, JavaScript, and health analytics.

---

##  Features

-  BMI Analysis
-  PCOS Risk Screening
-  Personalized Meal Plans
-  Exercise Recommendations
-  Water Intake Tracking
-  Lifestyle Risk Detection
-  Pregnancy Cravings Guidance
-  Sinhala & English Language Support
-  AI-Based Health Insights
-  Interactive Dashboard UI

---

##  Technologies Used

### Frontend
- HTML
- CSS
- JavaScript

### Backend
- Python
- Flask

### Machine Learning
- Scikit-learn
- Pandas

### Deployment

## ⚙️ Installation

```bash
git clone https://github.com/Chathumi01/health-risk-dietary-system.git

cd health-risk-dietary-system

pip install -r requirements.txt

python3 -m backend.app
```
